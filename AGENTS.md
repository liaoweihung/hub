# Hub Website Maintenance Rules

This repository hosts the DiamondL project homepage and the pharmacy work tool directory.

## Pharmacy Work Tool Directory

- `pharmacy-tools.html` is the independent `藥局工作用工具` directory. List each published tool with its name, a concise description, and its correct URL.
- `index.html` contains a link to `./pharmacy-tools.html`, not the full tool list. Keep this entry last, immediately after `藥師自我學資料分享`.
- Tool implementations and assets can remain in the separate `pteduimg` repository. Use their full published URLs under `https://liaoweihung.github.io/pteduimg/`, preserving nested paths.
- Whenever a pharmacy work tool is added, modified, renamed, moved, retired, or removed, check this directory and the homepage entry in the same task. Update affected names, descriptions, URLs, ordering, availability, and displayed tool counts. Do not automatically publish prototypes or hidden tools.
- Coordinate tool return links and the `pteduimg/calc.html` directory link with `https://liaoweihung.github.io/hub/pharmacy-tools.html`. Include navigation generated by shared JavaScript shells in this check.
- Verify homepage-to-directory navigation, directory-to-tool links, tool return links, and mobile layout after relevant changes. If no hub edit is needed, report that it was checked and remains consistent.

## Repository and Publishing Boundaries

- Hub remote: `https://github.com/liaoweihung/hub.git`.
- Tool implementation remote: `https://github.com/liaoweihung/pteduimg.git`.
- Keep changes and commits in their respective repositories. A local hub checkout nested under `pteduimg/output/hub/` must not be staged in the parent repository.
- When publishing is requested, commit/push each affected repository separately. Publish a new hub directory page before links that depend on it, and report both repositories' results when both changed.
- If the other repository is unavailable, report the outstanding synchronization work rather than silently treating it as complete.
